这里改变的
究竟是什么？

模型始终生成 50 步动作块。改变的是 LeRobot 的 n_action_steps：每次预测后，从这块中连续执行 K 步，再用新的观测调用模型。

01 / 视频案例

视频展示固定 seed 1000、初态 0 的单次轨迹。统计表另用 seed 1000–1099 和 50 个初态配对评测，每格 100 个 episode。

02 / 推理计时

在动作块生成处统计真实模型调用；每次调用前后同步 CUDA。记录每次调用延迟、episode 推理累计时间、完整 rollout 时间及成功率。

03 / 结果边界

只测 Spatial、Object、Goal 各自的 task 0。推理延迟来自 RTX 3090 上的同步仿真，不代表真机控制频率或完整 suite 表现。

OBSERVATION

更少调用，
成功率因任务而异。

K 从 1 增至 20 后，三个任务的平均推理累计时间减少约 18–23 倍。Spatial 和 Object 的成功率上升，Goal 的成功率下降。K 的取舍取决于任务是否需要频繁根据新观测修正动作。
