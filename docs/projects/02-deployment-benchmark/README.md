# 02 · 部署性能测评

**状态：规划中。** 本项目衡量同一个 VLA checkpoint 在不同推理与部署路径中的运行成本，并同时报告任务成功率，避免只比较速度。

## 目标与交付

固定任务、初态、seed、checkpoint 和观测尺寸，测量端到端延迟、推理耗时、吞吐、显存峰值和任务成功率；报告 p50/p95/p99、失败原因和运行环境。先复用 01 项目已验证的模型与 LIBERO 成功率基线，再引入新的执行路径。

每次实验应保存可复算的原始时间戳、命令、配置、模型哈希、环境信息和逐 episode 结果。最终交付包括运行入口、配置、验证脚本、对照报告和明确的计时边界。

## 代码与依赖

共享评测协议位于 `src/vla_inference_engine/benchmark/`，统一入口位于 `src/vla_inference_engine/cli.py`。性能采集和报告模块尚未实现。本项目开始时应从现有同步 rollout 建立测量基线，不改写 01 项目的固定正式结果。

## 建议验收

在固定 workload 上可重复得到延迟分布、吞吐、显存与成功率；同一配置能从原始记录重新生成报告；计时覆盖与同步边界有说明；对照实验只改变被研究的部署变量。未通过任务成功率门槛的加速配置单独报告，不能只以更快作为通过条件。
