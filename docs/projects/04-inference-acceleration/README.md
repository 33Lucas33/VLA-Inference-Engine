# 04 · 推理加速

**状态：规划中。** 本项目尝试降低 VLA 推理延迟和资源占用，并测出这些改动对任务成功率的影响。

## 目标与边界

候选方向包括模型编译、精度设置、图像前处理、动作块执行和运行时资源配置。每次实验固定 checkpoint、任务、初态和 seed，只改变一个主要因素。所有结果与 01 项目的原始同步基线对照，并使用 02 项目的延迟、吞吐、显存和成功率报告口径。

当前正式协议使用 `compile_model=false`；已有 SmolVLA checkpoint 的训练配置包含训练侧编译设置，但这不等于本项目已有推理加速评测能力。现阶段尚未实现可复现的加速矩阵或报告生成器。

## 建议交付与验收

交付包括可切换的优化配置、运行命令、固定 workload、原始记录、结果报告和回滚到未优化基线的方法。验收要求报告延迟分布、吞吐、显存、成功率和失败案例；只有在任务质量满足预先设定的门槛后，才将优化配置标为推荐。训练编译耗时与部署推理耗时分别记录。
